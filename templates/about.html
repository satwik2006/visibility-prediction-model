ABOUT THE PROJECT

Travel guidance powered by
machine-learning visibility prediction.

RouteVision combines a Flask web application, live weather inputs, OpenStreetMap place data and a trained Scikit-learn model to estimate visibility at multiple locations along a journey.

How the system works

Step 1Find route coordinates
Step 2Collect weather features
Step 3Predict visibility with ML
Step 4Generate safety guidance

The visibility model was trained using the Global Weather Repository dataset. Risk and recommendation rules use transparent road-safety thresholds so the result can be explained clearly.

Important limitation

This is an academic decision-support project, not an official navigation or weather-warning service. Predictions can differ from actual conditions because weather may change suddenly and route checkpoints are geographic approximations.
